# README — Практическая работа №6
## JSON API и JWT

### 1. Описание проекта

Проект представляет собой REST API для каталога товаров, разработанный на языке PHP с использованием MySQL. API обеспечивает обмен данными в формате JSON и использует JWT (JSON Web Token) для аутентификации пользователей.

### 2. Используемые технологии

- PHP 8.5
- MySQL
- Composer
- Библиотека firebase/php-jwt
- JSON
- HTTP REST API

### 3. Основные возможности

- Получение списка товаров.
- Получение информации об отдельном товаре.
- Авторизация пользователей.
- Создание JWT-токенов.
- Проверка токена при выполнении защищённых запросов.
- Создание новых товаров.
- Редактирование и удаление товаров с проверкой прав доступа.
- Проверка входящих данных и обработка ошибок.

### 4. Роли пользователей

В проекте предусмотрено три уровня доступа:

- **Visitor** — просмотр списка товаров и информации об отдельном товаре.
- **User** — просмотр каталога и создание новых товаров.
- **Admin** — полный доступ к операциям каталога, включая изменение и удаление товаров.

Права пользователя проверяются на сервере при каждом защищённом запросе.

### 5. JWT-аутентификация

Для авторизации используется JWT с алгоритмом HS256.

Срок действия токена составляет 900 секунд.

После успешного входа сервер возвращает токен. Для выполнения защищённых запросов необходимо передавать его в HTTP-заголовке:

    Authorization: Bearer <access_token>

### 6. API-маршруты

| Метод | Маршрут | Назначение |
|---|---|---|
| POST | /api/login | Авторизация пользователя |
| GET | /api/items | Получение списка товаров |
| GET | /api/items/{id} | Получение товара |
| POST | /api/items | Создание товара |
| PUT | /api/items/{id} | Изменение товара |
| DELETE | /api/items/{id} | Удаление товара |

### 7. Запуск проекта

1. Установить PHP и Composer.
2. Установить зависимости командой:

    composer install

3. Настроить подключение к MySQL в файле config.local.php.
4. Убедиться, что база данных и необходимые таблицы созданы.
5. Сгенерировать ключ JWT:

    php bin/p06-key.php

6. Запустить встроенный PHP-сервер:

    php -S localhost:8080 router.php

После запуска API будет доступен по адресу:

    http://localhost:8080/api/

### 8. Пример авторизации

Запрос:

    POST /api/login
    Content-Type: application/json

Тело запроса:

    {
        "email": "user@example.test",
        "password": "User123456!"
    }

При успешной авторизации сервер возвращает JWT-токен и информацию о пользователе.

### 9. Проверка проекта

Для проверки работоспособности API используется предоставленный проверочный скрипт check.php.

Примеры запуска:

    php check.php http://localhost:8080 routes
    php check.php http://localhost:8080 input
    php check.php http://localhost:8080 login user@example.test admin@example.test
    php check.php http://localhost:8080 catalog user@example.test admin@example.test

Проверка охватывает маршруты API, обработку входных данных, авторизацию, права доступа и операции с каталогом.

### 10. Структура проекта

- src/Api/ — основные классы API.
- public/ — публичная часть приложения и точка входа API.
- bin/ — вспомогательные скрипты.
- vendor/ — установленные зависимости Composer.
- var/ — служебные файлы, включая ключ JWT.
- router.php — маршрутизация запросов.
- composer.json — настройки и зависимости проекта.
- README.md — описание проекта и инструкция по запуску.
